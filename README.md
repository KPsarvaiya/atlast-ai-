# 🤖 Atlas AI

**Atlas AI** is an AI-powered financial assistant that works through Telegram.  
The current project uses **Python**, **Telegram Bot API**, and **Google Gemini API** to provide a finance-focused conversational AI experience.

---

## 📌 Project Status

**Current status:** Working MVP

The current version successfully supports:

- Telegram bot communication
- `/start` command
- Normal text messages
- Google Gemini AI responses
- Finance-focused AI assistant behavior
- Environment-variable configuration using `.env`
